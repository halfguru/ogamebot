<!--
OGameX fleet events use TWO endpoints:

1. Eventbox (JSON): GET /ajax/fleet/eventbox/fetch
   Returns JSON: {
     "hostile": 2,        // count of hostile fleets
     "friendly": 3,       // count of own fleets
     "neutral": 0,
     "newAjaxToken": "...",
     "serverTime": "2026-05-03T12:00:00+00:00"
   }
   - Used for IsUnderAttack() (hostile > 0)
   - Used for GetServerTime() (serverTime field)
   - Does NOT contain individual fleet details

2. Eventlist (HTML): GET /ajax/fleet/eventlist/fetch
   Returns HTML fragment (Blade template) with fleet movement rows.
   Each row contains: fleet ID, mission icon, origin coords, destination coords,
   arrival time countdown, ship composition, resource cargo.
   - Used for GetFleets() (parse all fleet movements)
   - Used for GetAttacks() (filter for hostile mission types)
   - HTML parsing required (goquery)

Research IDs for GetResearch():
- GET /research → HTML page with technology items
- Same pattern as buildings: data-technology attributes with levels
- Research IDs are different from building IDs (research has own ID space)

Construction queue for GetConstructions():
- Active build queue visible on /resources page (and /facilities, /research)
- Parse active building construction countdown
- Parse active research countdown
- Both can be empty (ID=0, Level=0, Countdown=0)

Slots for GetSlots():
- GET /fleet?cp=<planetID> → parse slot counts from HTML
- Fleet slots: "InUse/Total" format
- Expedition slots: "ExpInUse/ExpTotal" format

Server info:
- GetServerSpeed: likely from /overview or a settings page, or hardcoded in OGameX config
- GetServerVersion: parse from footer HTML or about page
- GetServerTime: extract serverTime from eventbox JSON response
-->
