**3. Create `internal/dashboard/hub.go`** — WebSocket hub using gorilla/chat pattern:
- `Hub` struct with `clients map[*client]bool`, `broadcast chan WSMessage`, `register/unregister chan *client`
- `client` struct with `hub *Hub`, `conn *websocket.Conn`, `send chan []byte`
- `NewHub() *Hub` constructor
- `Hub.Run(ctx)` goroutine: select on register/unregister/broadcast channels
- `Hub.Broadcast(msgType string, data interface{})` — creates WSMessage, JSON-marshals, sends to broadcast channel
- Each client: `readPump` goroutine (reads from WS, handles pong, detects disconnect → unregister) and `writePump` goroutine (reads from send channel, writes to WS with ticker for ping)
- Upgrader with `CheckOrigin: func(r *http.Request) bool { return true }` (CORS handled at server level)
- Write deadline of 10s on each WS write, ping every 54s, pong wait 60s

**4. Create `internal/dashboard/handlers.go`:**
- `Handlers` struct with `stateMgr StateReader`, `db *sql.DB`, `hub *Hub`
- `StateReader` interface (same as builder's BuilderStateReader plus GetFleets, GetServerSpeed — actually just use the full Manager's public methods)

  ```go
  type StateReader interface {
  ```

- `NewHandlers(stateMgr StateReader, db *sql.DB, hub *Hub) *Handlers`

Handler methods:
- `handlePlanets(w, r)` — GET /api/planets. Get planets from stateMgr, for each planet get resources + buildings, convert to APIPlanet slice, write JSON.
- `handleFleets(w, r)` — GET /api/fleets. Get fleets from stateMgr, convert to APIFleet slice, write JSON.
- `handleResearch(w, r)` — GET /api/research. Get research from stateMgr, convert to APIResearch, write JSON.
- `handleBuildEvents(w, r)` — GET /api/events/builds. Query `SELECT id, planet_id, building_name, from_level, to_level, cost_metal, cost_crystal, cost_deut, roi_score, created_at FROM build_events ORDER BY id DESC LIMIT 50` from db, scan to APIBuildEvent, write JSON.
- `handleFleetSaveEvents(w, r)` — GET /api/events/fleet-saves. Query `SELECT id, planet_id, fleet_id, dest_planet_id, attack_id, sent_at, recall_at, completed, recalled FROM fleet_save_events ORDER BY id DESC LIMIT 20`, write JSON.
- `handleFarmAttacks(w, r)` — GET /api/events/farm-attacks. Query `SELECT id, fleet_id, planet_id, target_galaxy, target_system, target_position, ships_sent, metal_looted, crystal_looted, deuterium_looted, sent_at FROM farm_attacks ORDER BY id DESC LIMIT 50`, write JSON. Format targetCoord as "galaxy:system:position".

All handlers: set `Content-Type: application/json`, encode errors as `{"error": "message"}` with appropriate status code.

  ```
  mux.HandleFunc("GET /api/planets", s.handlers.handlePlanets)
  mux.HandleFunc("GET /api/fleets", s.handlers.handleFleets)
  mux.HandleFunc("GET /api/research", s.handlers.handleResearch)
  ```

| Threat ID | Category | Component | Disposition | Mitigation Plan |
