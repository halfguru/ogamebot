<objective>
Implement OGameX authentication: login via email/password, CSRF token extraction from HTML, automatic token refresh from JSON responses, and session re-authentication on expiry.

Purpose: This is the foundation of the entire bot — every subsequent phase depends on the client being authenticated. OGameX uses Laravel Fortify session-based auth with CSRF token rotation, which must be handled thread-safely since multiple goroutines (state manager + workers) make concurrent requests.

Output: Working login flow that authenticates with OGameX, maintains CSRF tokens, and handles session expiry gracefully.
</objective>

<!--
Login flow:
1. GET /login → parse HTML with goquery → extract <meta name="csrf-token" content="...">
2. POST /login with email, password, _token (CSRF) → cookie jar captures laravel_session + XSRF-TOKEN
3. On every subsequent request, cookie jar auto-sends both cookies
4. For POST requests, also send _token parameter with current CSRF token
5. Every JSON response may contain newAjaxToken field → update stored token

CSRF failure recovery:
- HTTP 419 → re-login (GET /login → POST /login) → retry original request once
- Redirect to /login → re-login → retry

Token refresh:
- Extract newAjaxToken from every JSON response body
- Update stored csrfToken (mutex-protected)

   - Find `<meta name="csrf-token">` via `doc.Find("meta[name='csrf-token']")`
   - Extract `content` attribute: `.Attr("content")`
   - Return error if token not found: `fmt.Errorf("csrf token not found in login page")`

2. **`func (c *Client) Login(ctx context.Context) error`** — replaces the stub in client.go:
   - Step 1: GET `/login` to fetch the login page HTML
     ```go
     req, _ := http.NewRequestWithContext(ctx, http.MethodGet, c.baseURL+"/login", nil)
     resp, err := c.httpClient.Do(req)
     ```
   - Step 2: Parse CSRF token from response body using `extractCSRFToken(resp.Body)`
   - Step 3: Store token via `c.setCSRFToken(token)`
   - Step 4: POST `/login` with form data:
     ```go
     data := url.Values{}
     data.Set("email", c.email)
     data.Set("password", c.password)
     data.Set("_token", c.csrfToken())
     ```
   - Step 5: Check response — success is a redirect (302) to overview page. If status is 200 with login page again, credentials were wrong.
   - Step 6: GET `/login` again to verify we're NOT redirected (i.e., we're authenticated) — or just GET `/overview` and check for 200.
   - Log at info level: "Logged in to OGameX", and at debug level: the CSRF token value (first 8 chars only for security).
   - Return `fmt.Errorf("login failed: status %d", resp.StatusCode)` on failure.

3. **`func (c *Client) Logout(ctx context.Context) error`** — replaces the stub:

   - Clear stored CSRF token
   - Return nil on success

   ```go
       c.mu.Lock()
       defer c.mu.Unlock()
       return c.csrfToken
   }

   func (c *Client) setCSRFToken(token string) {
       c.mu.Lock()
       defer c.mu.Unlock()
       c.csrfToken = token
   }
   ```

1. **`func (c *Client) doGet(ctx context.Context, path string) ([]byte, error)`**:
   - Build request: `http.NewRequestWithContext(ctx, http.MethodGet, c.baseURL+path, nil)`
   - Execute via `c.httpClient.Do(req)`
   - Check for redirect to `/login` — if resp.Request.URL.Path starts with `/login`, session expired:
     - Call `c.login(ctx, c.email, c.password)` (private re-login) — BUT Login is already a method. Since Login is public, just call `c.Login(ctx)` for re-auth.
     - Retry the GET once after re-login.
     - If retry also redirects, return error.
   - Read and return body bytes.
   - Log at debug level: method, path, status, duration.

2. **`func (c *Client) doPost(ctx context.Context, path string, data url.Values) ([]byte, error)`**:
   - Set `_token` in data: `data.Set("_token", c.csrfToken())`
   - Build POST request with form-encoded body:
     ```go
     req, _ := http.NewRequestWithContext(ctx, http.MethodPost, c.baseURL+path, strings.NewReader(data.Encode()))
     req.Header.Set("Content-Type", "application/x-www-form-urlencoded")
     ```
   - Execute and check status:
     - **419 (CSRF token mismatch)**: Re-login via `c.Login(ctx)`, update token, retry POST once.
     - **401**: Re-login, retry once.
     - **Redirect to /login**: Re-login, retry once.
   - On success (2xx or 3xx to non-login page): try to extract `newAjaxToken` from response body if it's JSON.
   - Read and return body bytes.

3. **`func (c *Client) doAJAX(ctx context.Context, method, path string, data url.Values) ([]byte, error)`**:
   - Wrapper that uses doGet or doPost based on method.
   - On response, attempt to parse `{"newAjaxToken": "..."}` from body:
     ```go
     var ajaxResp struct {
         NewAjaxToken string `json:"newAjaxToken"`
     }
     if err := json.Unmarshal(body, &ajaxResp); err == nil && ajaxResp.NewAjaxToken != "" {
         c.setCSRFToken(ajaxResp.NewAjaxToken)
         c.log.Debug("CSRF token refreshed from response")
     }
     ```
   - Return body bytes (full body, not just the parsed struct — callers need the full response).

4. **`func (c *Client) doAJAXGet(ctx context.Context, path string) ([]byte, error)`**:
   - Convenience: `c.doAJAX(ctx, http.MethodGet, path, nil)`

5. **`func (c *Client) doAJAXPost(ctx context.Context, path string, data url.Values) ([]byte, error)`**:
   - Convenience: `c.doAJAX(ctx, http.MethodPost, path, data)`
