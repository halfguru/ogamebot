**Part C: Distance calculation**

Define `func CalcDistance(from, to model.Coordinate) int`:
- Same system: abs(from.Position - to.Position)
- Same galaxy, different system: 5*abs(from.System-to.System) + abs(from.Position-to.Position)
- Different galaxy: 20000*abs(from.Galaxy-to.Galaxy)

**Part D: Flight duration**

Define `func flightDuration(distance int, speed int, from, to model.Coordinate, ships model.Ships, research model.Research) time.Duration`:
- Speed is 1-10 representing 10%-100%
- Use the slowest ship in the fleet to determine flight time
- Duration = (duration at 100% speed) * (10 / speed)
- Base duration formula: distance / (slowestEffectiveSpeed * universeSpeed)
- OGame formula: flightTime = round((3500 / speed * sqrt(distance * 10 / slowestSpeed) + 10) * (1.0 / universeSpeed)) seconds
  Where speed is 1-10 (the speed setting), slowestSpeed is the slowest ship's effective speed
- Use universeSpeed = 1 as default (will be configurable later)

- Simplified OGame formula per ship: consumption = baseConsumption * count * (distance / 35000) * ((speed/10 + 1) / 2)^2)
- Sum consumption across all ship types

**Part B: CalcEscapeRoutes function**

```go
func CalcEscapeRoutes(
    origin model.Planet,           // endangered planet (origin of fleet-save)
    ships  model.Ships,            // ships on the planet
    resources model.Resources,     // resources on the planet
    ownPlanets []model.Planet,     // candidate destinations (excluding origin)
    attacks []model.AttackEvent,   // active attacks for safety scoring
    research model.Research,       // drive tech levels for speed/fuel calc
) []EscapeRoute
```

Algorithm:
1. If no ships on origin → return empty slice (nothing to save)
2. If no destinations → return empty slice (nowhere to go — logged by caller)
3. For each destination planet (skip origin):
   a. Skip if destination == origin (same coords)
   b. For each speed setting 10, 9, 8, ..., 1 (prefer high speed):
      - Calculate distance from origin to destination
      - Calculate fuel consumption for all ships at this speed
      - If fuel > available deuterium: skip this speed (fuel insufficient)
      - Calculate flight duration
      - Calculate resources loadable: metal + crystal + (deuterium - fuel)
      - Calculate safety score
4. Sort all viable routes by safety score ascending (lower = safer)

**Part C: Safety scoring**

```go
func calcSafetyScore(route EscapeRoute, attacks []model.AttackEvent) int
```

Scoring criteria (lower = safer):
- Base: 0
- +1000 if destination has incoming hostile attack arriving before our fleet would arrive
- +500 if destination is a planet (moons are safer — no phalanx)
- -100 if destination is a moon (bonus for moon destination)
- +distance/50 (farther = riskier, slight penalty)
- +fuelCost/10000 (more fuel = riskier)

**Part D: Coordinate type handling for moons**

When origin is a moon (`origin.IsMoon == true`):
- Origin coordinate type must be "moon" (already set in Planet)
- Destination coordinate type should use destination's actual type
- Deploy from moon to own planet is safest (moon can't be phalanxed, deploy is clean)

When origin is a planet:
- Deploy to own moon is preferred (moon can't be phalanxed)
- Deploy to own planet is acceptable (phalanx-visible but recalled fleet is invisible)

The route's Dest field should use the destination planet's actual Coordinate (which has Type already set).

Write comprehensive table-driven tests in `escape_test.go` covering all the behavior cases listed above.
